# カレンダー工数管理（EnkinGT風・追加コストゼロ版）

Googleカレンダーに入れた予定を毎朝自動で取り込み、工数集計・タスク予実・ボード／ガント・日報まで行う。
メンバーの追加作業は「予定の件名に少しルールを足す」だけ。

## できること（EnkinGTとの対応）

| EnkinGT | この仕組み |
|---|---|
| タスク管理（担当・工数・期限） | 「タスク」シート／Web画面。IDは自動採番（T-0001） |
| ボード | Web画面「ボード」：ドラッグ＆ドロップでステータス変更 |
| ガントチャート | Web画面「ガント」：案件ごと、今日線、消化率、期限超過を赤表示 |
| タイム（カレンダー連携） | 予定の件名か説明に `T-0012` を書くとそのタスクの実績に自動計上 |
| 予実管理 | 予定工数 vs 実績 → 消化率・残工数・判定（順調／注意／工数超過／期限超過） |
| 日報 | その日の予定から業務内容を自動生成 → 所感を書いて保存 |
| ─ | 業務カテゴリ別集計・部署間の移管シミュレーション（今回の目的） |
| ─ | **管理画面でメール登録 → その人のカレンダーを収集**（接続テストでアクセス状況を表示） |
| ─ | **メンバーの予定を修正**：週カレンダーで件名・時間・説明を変更、予定の追加、件名を変えずにカテゴリ／タスクを付け直し |

カメラでの在席共有、自動翻訳、Slack/GitHub連携は対象外。

## 予定の書き方（メンバー向け・どれか1つでOK）

1. **タスクID**：件名か説明に `T-0012` → 例「T-0012 A社見積作成」
2. **カテゴリタグ**：件名に `【納期調整】` か `#納期調整`
3. **何もしない**：件名のキーワード（見積・納期・会議…）で自動判定。判定できなければ「未分類」
- 案件は `@案件名`（例「【見積もり取得】@A社更新 仕様確認」）
- 終日予定・辞退した予定・不在／勤務場所・除外キーワード（休憩、昼食…）は取り込まない

## 導入手順（管理者が1回だけ・15分）

1. Googleスプレッドシートを新規作成 →「拡張機能」→「Apps Script」
2. `Code.js` の中身を `コード.gs` に貼り付け、HTMLファイル `index` を追加して `index.html` を貼り付け
3. 左の「サービス ＋」→ **Google Calendar API** を追加（または「プロジェクトの設定」で appsscript.json を表示して置き換え）
4. スプレッドシートを再読み込み → メニュー「工数管理」→「① 初期設定」→ 権限を許可
5. メニュー「毎朝6時の自動取り込みをON」
6. Apps Script「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、
   実行ユーザー「自分」、アクセス「組織内の全員」→ URLをチームに共有
7. **各メンバー**：Googleカレンダーの「設定と共有」→「特定のユーザーまたはグループと共有する」で管理者を追加
   - 予定も修正したい → 権限「**予定の変更**」
   - 集計だけ → 「予定の詳細をすべて表示」
8. Web画面「管理」タブで氏名・部署・メールアドレスを登録 → 自動で接続テスト（編集可／閲覧のみ／アクセス不可）→「今すぐ取込」

## 予定の修正（Web画面「カレンダー」タブ）
- 週表示で予定を確認（色＝カテゴリ、黄色＝未分類、灰色斜線＝集計対象外）
- 下の表でカテゴリ／タスクを選ぶだけで分類を修正（件名は変わらない。予定の非公開プロパティに保存）
- 予定をクリック → 件名・日付・時間・説明を修正、または「＋予定を追加」で後から工数を記録
- 参加者への通知は送らない。保存後、その日の工数ログを自動で取り込み直す
- 他の人が主催した会議は件名・時間を変えられない（Googleカレンダーの仕様）。分類だけ保存できる
- 見られる・直せるのは **本人（自分のカレンダー）と管理者のみ**。管理者は設定シートL13にメールを追加

## 権限について
- 予定の修正のため、カレンダーの権限は読み書き（calendar）。削除機能は付けていない
- 本人・管理者の判定にログインメールを使うため、**Google Workspace（同じ組織）での運用が前提**。個人Gmail同士だと閲覧者のメールが取得できず、管理画面・カレンダータブが使えない
- 接続テストで管理者のカレンダー一覧にメンバーのカレンダーが（非表示で）追加される

## ファイル
- `Code.js` … サーバー処理（取り込み・集計・タスク更新・シート作成）
- `index.html` … Web画面（ボード／ガント／予実・工数／日報）
- `appsscript.json` … マニフェスト（Calendar API v3、タイムゾーン Asia/Tokyo）
